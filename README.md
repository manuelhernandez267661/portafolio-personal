# Portafolio personal

Sitio estático y adaptable para presentar a Manuel Hernandez, programador en proceso. Incluye una galería de proyectos de ejemplo, habilidades, contacto y enlaces sociales de muestra.

## Estructura

- `index.html`: contenido semántico y accesible del sitio.
- `css/styles.css`: paleta, componentes, estados interactivos y diseño responsive.
- `js/main.js`: menú desplegable para pantallas pequeñas.
- `assets/img/`: ilustraciones SVG locales para los proyectos.
- `assets/icons/`: iconos sociales y favicon.

## Uso

Abre `index.html` en un navegador. No requiere instalación, conexión a internet ni proceso de compilación. Usa Arial como tipografía del sistema.

## Personalización

Los proyectos son ejemplos de práctica y sus botones llevan a la sección de contacto; no enlazan a repositorios inexistentes. El correo `manuel.hernandez@example.com` usa un dominio reservado para ejemplos. Los enlaces de GitHub e Instagram llevan a sus páginas generales, no a perfiles personales. Sustituye estos datos y destinos por los definitivos antes de publicar.
